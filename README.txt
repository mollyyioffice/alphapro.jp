ALPHA PRO Japan landing page - GitHub Pages package

Upload contents of this folder to the ROOT of your GitHub repository.
Keep index.html and the assets folder together.

Required structure:
  index.html
  assets/images/
  assets/videos/
  assets/posters/

GitHub Pages setup:
  1. Open repository Settings > Pages.
  2. Under Build and deployment, choose Deploy from a branch.
  3. Select branch main and folder /(root), then Save.
  4. Wait for deployment and open the URL shown in Settings > Pages.

All product photos, video files, and video posters are stored locally in assets/.
Video files use H.264 MP4 for broad browser compatibility.
Do not upload only index.html; upload the entire assets folder too.
