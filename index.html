ALPHA PRO
01 ／ データとジョー

対応できる鍵は、データとジョーで決まります。

鍵の断面ごとに固定の方法が変わり、型番とキーコードからピット番号を引きます。この二つが揃って、切削できる鍵の範囲が決まります。

POINT 01

断面が違えば、ジョーも違う

単一規格、ディンプル、チューブラー、車のキー。断面が違えば、キーを固定する方法も変わります。

POINT 02

型番とキーコードから、ピットを引く

6分類のキーデータを収録しています。キーコードが分かる鍵は、コードを入力して直接呼び出せます。

POINT 03

データに無い鍵は、デコードして複製する

原本をデコーダーで読み取り、ピットを割り出して切削します。読み取りと切削は、同じ機械の中で完結します。

POINT 04

現地の特殊な鍵は、ジョーで受ける

どの鍵をどのジョーで受けるか。その整理が、対応できる範囲を決めます。

02 ／ 製品

Alpha Pro の構成

既存モデル Alpha のアップグレード版です。検索、デコード、切削を一つの画面にまとめています。

01 / DATA

6分類のキーデータ

片面キー414（メデコを含む）、海外の車208、ディンプル135、中国の車94、バイク90、チューブラー16。キーコードからピット番号を検索できます。

02 / USE

車、住宅、バイク、ディンプル、チューブラー

用途は自動車、住宅、バイク、ディンプルキー、チューブラーキーの切削です。メデコなどの特許キーも、この分類に含まれます。

03 / JAW

現地の特殊な鍵には、ジョーを定制

標準のジョー（S1〜S13）で収まらない鍵は、鍵の形状に合わせてジョーを設計・製作します。仕様は、鍵の形状をお預かりして相談します。

04 / JAPAN

日本市場：MIWA U9 と MIWA PR

MIWA U9 の S1／S2 キー、MIWA PR キー。画面の選択肢から呼び出して、デコードとカットを行います。

05 / PRECISION

3軸ボールねじ／0.0025mm

X・Y・Z の各軸にボールねじを採用し、Z軸はDCブラシレスモーターでカッターを直接制御。デコーダーとカッターは同時装着で、交換後の高さ調整は不要です。

06 / OPERATION

日本語を含む、18言語の画面

Android 産業用ディスプレイに、検索・デコード・切削の手順を集約。データベースに無い鍵も、デコード→カットの手順で複製できます。

03 ／ 日本市場での対応

日本市場では、MIWA U9 と MIWA PR を切削できます。

01 ／ U9 S1

Alpha Pro で Miwa U9 キーを複製する

02 ／ U9 S2

Alpha Pro（S2ジョー）で Miwa U9 をカットする

03 ／ MIWA PR

Miwa PRキーを Alpha Pro で切削する
